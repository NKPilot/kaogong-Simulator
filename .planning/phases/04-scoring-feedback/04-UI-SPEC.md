4. Covered dots when green/red are already in use for status differentiation -- accent can serve as alternative

- Borders
- Backgrounds (except button fills via Ant Design `type="primary"`)
- Non-interactive decorative elements

### Card States

Each scoring card exists in one of four states:

| State | Visual | Condition | Source |
|-------|--------|-----------|--------|
| **Scored** | Full card: coverage fraction, dot breakdown, LLM feedback, collapsible transcript, "重新评分" button | Scoring completed successfully | D-02, D-06, D-08, D-11 |
| **Pending** | Card skeleton with `Spin` indicator + "评分中..." text | Scoring still in progress when user arrives | D-09 |
| **Error** | Card with error icon, "评分失败" heading, "点击重试" button | Scoring failed after auto-retry | D-10 |
| **Empty** | Full-page `Result` component with "暂无评分数据" message + "返回题库" button | User navigates to /results without interview data | Default guard |

## Interaction Contract

### 1. Page Entry (D-09)

- User arrives at `/results` via automatic navigation after the last question's transition delay (2500ms, from Phase 3 `QuestionInterviewPage`).
- The page immediately polls or reads from the scoring store for available results.
- Cards for already-scored questions render immediately.
- Cards for in-progress scoring show the Pending state (skeleton + spin + "评分中...").
- No manual refresh required -- the store updates reactively as scoring results arrive.

### 2. Coverage Dot Visualization (D-06)

- Each scorePoint in the question's `scorePoints` field is parsed into individual point entries.
- Each entry displays as a row with:
  - A colored dot (12px diameter circle)
  - The status label ("已覆盖", "部分覆盖", or "未覆盖")
  - The score point text
- Dot color mapping:
  - Green `#52C41A`: "已覆盖"
  - Orange `#FA8C16`: "部分覆盖"
  - Red `#FF4D4F`: "未覆盖"
- The coverage fraction displays prominently: e.g., **3/5 已覆盖** in 28px/700.
- Dots use `display: inline-flex` with `align-items: center`, `gap: 8px`.

### 3. Collapsible ASR Transcript (D-08)

- Uses Ant Design `Collapse` component.
- Default state: collapsed.
- Panel header: "语音识别原文" (13px/400, text secondary color).
- Panel body: ASR-transcribed text of the user's spoken answer (14px/400, monospace styling optional for transcript feel).
- Only visible when the card is in the "Scored" state and a transcript is available.

### 4. Re-Score Button (D-11)

- Ant Design `Button type="primary"`, label "重新评分".
- No confirmation dialog -- immediate action per D-11's direct intent.
- On click:
  1. Card transitions to Pending state (skeleton + "评分中...").
  2. Backend receives re-score request for that specific question.
  3. On completion, card transitions back to Scored state with updated results.
  4. On failure, card transitions to Error state with "评分失败" + "点击重试".

### 5. Error Retry (D-10)

- Error card displays:
  - Error icon (red `#FF4D4F`)
  - "评分失败" text (16px/700, red)
  - "点击重试" button (Ant Design `Button`, type="default", outlined in red)
- Other cards are unaffected -- scoring continues independently.

### 6. Page Exit CTA

- "返回题库" button at page bottom (below all cards).
- Ant Design `Button`, `type="default"`, outlined with `color: #BE1E2D` border.
- Navigates to `/` (QuestionBank page) on click.
- Uses `useNavigate()` from React Router.

## Animation Contract

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Card entry (staggered) | Fade in + translateY(8px -> 0) | 300ms per card, 100ms stagger | ease-out |

## Responsive Behavior

- Content area: `max-width: 960px`, `margin: 0 auto`, `width: 100%`.
- Cards: full width within content area, no fixed widths.
- At viewports below 640px: reduce card padding from `24px` to `16px`, score display from `28px` to `24px`.
- The Ant Design `Layout.Content` padding (`32px`) should reduce to `16px` on narrow viewports.

**Source:** Content width from `AppLayout`. Narrow-viewport adjustments are a sensible default for mobile-first.
