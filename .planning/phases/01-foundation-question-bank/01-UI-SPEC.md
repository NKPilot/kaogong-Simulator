## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none (Ant Design) | D-03: Ant Design as UI library |
| Component library | Ant Design v5 (`antd`) | D-03 |
| Icon library | `@ant-design/icons` | Derived from antd dependency |
| Font | System font stack (Ant Design default: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif, "Apple Color Emoji", "Segoe UI Emoji"`) | Ant Design default -- no override needed |
| State management | Zustand | D-05 |
| Routing | React Router v6 | D-04 |

**Theme customization method:** Wrap root `<App>` with Ant Design `<ConfigProvider>` passing a `theme` object:

```tsx
<ConfigProvider theme={{
  token: {
    colorPrimary: '#BE1E2D',
    // Overrides listed in Color section below
  },
  components: {
    Table: { ... },
    Button: { ... },
    Layout: { ... },
  }
}}>
  <RouterProvider router={router} />
</ConfigProvider>
```

**Ant Design components used in this phase:**

| Element | Component | Notes |
|---------|-----------|-------|
| Page header / app shell | `Layout`, `Layout.Header`, `Layout.Content` | Header with crimson red background |

| Header title | `Typography.Title` | App name in header |
| Meta labels | `Typography.Text` (type `secondary`) | Question metadata |

## Spacing Scale

**Base unit:** 4px (Ant Design default grid).

| Ant Token | Value | Usage |
|-----------|-------|-------|
| `paddingXXS` | 4px | Inner icon spacing, compact label padding |
| `paddingXS` | 8px | Table cell padding, tag spacing |
| `paddingSM` | 12px | Compact card padding, alert inner spacing |
| `padding` / `margin` | 16px | Default element spacing, table row padding, content padding |
| `paddingMD` | 20px | Section title padding |
| `paddingLG` | 24px | Card padding, panel padding, layout content margin |
| `paddingXL` | 32px | Layout content horizontal padding, page margins |
| `marginXXL` | 48px | Major section breaks, header bottom margin |
| `margin` *custom* | 64px | Page-level top/bottom spacing (not in Ant defaults, use CSS custom) |

**Exceptions:** none. Ant Design's 4px grid covers all Phase 1 spacing needs.

## Typography

**Strategy:** Use Ant Design's built-in typographic scale (based on 14px body) with no custom font overrides.

| Role | Ant Token | Size | Weight | Line Height | Usage |
|------|-----------|------|--------|-------------|-------|
| Body | `fontSize` | 14px | 400 (regular) | 1.571 (22px) | Question metadata, descriptions, table body text |
| Label / Caption | `fontSizeSM` | 12px | 400 (regular) | 1.5 (18px) | Secondary metadata, tags, hints |
| Small heading | `fontSizeLG` | 16px | 600 (semibold) | 1.4 (22.4px) | Question title in list, section headers |
| Medium heading | `fontSizeHeading3` | 24px | 600 (semibold) | 1.333 (32px) | Page title, "开始面试" button |
| Large display | `fontSizeHeading2` | 30px | 700 (bold) | 1.266 (38px) | Header app name / phase title |
| Interactive | `fontSize` | 14px | 500 (medium) | 1.571 (22px) | Button text, links, interactive labels |

**Note:** Font weights follow Ant Design's weight tokens (`fontWeightStrong: 600`). Use Ant Design's `<Typography>` components (`Title`, `Text`, `Paragraph`) to apply these automatically.

**Chinese font rendering:** The system font stack on Chinese systems (`PingFang SC`, `Microsoft YaHei`, `Noto Sans SC`) handles CJK characters well. No additional font import needed.

### Accent Reserved For

> Red (`#BE1E2D`) is reserved for the following elements ONLY:

1. **Layout header background** - app title bar
2. **Primary button** background ("开始面试")
3. **Selected checkbox** `:checked` state
4. **Question type tags** for 结构化小组 (the most serious type) -- other types use secondary colors
5. **Selection count badge** with count >= 3
6. **Table row hover** subtle red tint (`#FFF1F0`)
7. **Link color** within selection panel

**Never use accent for:** Background fills, card backgrounds, non-primary buttons, decorative borders, loading spinners, or any element that isn't explicitly listed above. Overuse of red will make the UI feel chaotic rather than authoritative.

### 3. Selection Flow States

| State | Condition | UI Behavior |
|-------|-----------|-------------|
| Empty | 0 selected | Alert warning: "请至少选择 3 道题". Button disabled (gray). |
| Partial | 1-2 selected | Alert warning persists. Button disabled. Count shows "已选择 N/4 题". |
| Ready | 3 selected | Alert disappears. Button enabled (primary, red). Count Badge shows "3". |
| Full | 4 selected | Button enabled. Checkboxes for remaining unselected rows disabled with tooltip "最多选择 4 道题". |
| Overflow prevented | User clicks row at 4 | `Prevent` the selection. Show `message.warning("每轮面试最多选择 4 道题")` via Ant notification. |

## Interaction Behavior Contract

### Row Click vs Checkbox Click

| Action | Behavior |
|--------|----------|
| Click row body (not checkbox) | Toggle expandable row to show question full text |
| Click checkbox | Toggle selection (add/remove from session) |
| Click type tag | No action (display only) |

### Selection Constraints

1. **Minimum 3:** "开始面试" button remains disabled until `selectedCount >= 3`.
2. **Maximum 4:** When `selectedCount === 4`, all unselected rows get `checkbox.disabled = true` with tooltip "每轮面试最多选择 4 道题".
3. **Unselecting from 4:** When user unchecks a checkbox and count drops to 3, re-enable all checkboxes.
4. **Persistence:** Selection state survives page navigation via Zustand store (app-wide).

### Navigation

| Interaction | Route | Notes |
|-------------|-------|-------|
| Initial load | `/` | Question bank page |
| "开始面试" click | `/exam-room` (Phase 2) | Route exists in Phase 1 but 404 page shown (or placeholder page) |

**Phase 1 constraint:** The "开始面试" button must navigate. If Phase 2 is not yet implemented, show a placeholder page with text "面试考场 (即将开放)". Otherwise, route to `/exam-room`.

## State Shape (Zustand)

```ts
interface QuestionBankStore {
  // Data
  questions: Question[];
  loading: boolean;
  error: string | null;

  // Selection
  selectedIds: string[];
  toggleSelect: (id: string) => void;
  isSelected: (id: string) => boolean;
  isMaxReached: boolean;       // computed: selectedIds.length >= 4
  canProceed: boolean;        // computed: selectedIds.length >= 3

  // Actions
  loadQuestions: () => Promise<void>;
  resetSelection: () => void;
}

interface Question {
  id: string;
  title: string;
  fullText: string;
  type: 'A' | 'B' | 'C' | '结构化小组';
  year: number;
  source?: string;
  scorePoints?: string[]; // Not displayed in Phase 1 but carried in data
}
```

## Accessibility Notes

| Check | Requirement |
|-------|-------------|
| Color contrast | Red on white header text must maintain 4.5:1 ratio. `#BE1E2D` on white (`#FFFFFF`) = 5.2:1 -- PASS. |
| Focus indicators | Ant Design default focus rings are sufficient |
| Keyboard navigation | Table rows + checkboxes must be reachable via Tab. Enter/space toggles expand row and checkbox respectively. |
| Screen reader labels | Checkbox should have `aria-label="选择{question.title}"` |
| Error announcements | Loading error should use `role="alert"` |
