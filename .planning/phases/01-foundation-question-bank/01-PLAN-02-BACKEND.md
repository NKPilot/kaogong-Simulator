# Plan 02: Backend FastAPI Scaffold (后端骨架搭建)

Create the FastAPI backend project structure using uv, with health check and question-serving endpoints. Uses Pydantic models for data validation, a service layer for data access, and routers for API organization. The backend reads from `backend/data/questions.json` (generated by Plan 01) and serves it via `GET /api/questions`. CORS is configured to allow requests from the frontend dev server at `http://localhost:5173`.

## Requirements

| Req ID | Description | Verification |
|--------|-------------|-------------|
| QB-01 | Backend serves question data via REST API | GET /api/questions returns 200 + array of 16 questions |
| QB-02 | Questions have IDs suitable for selection | Each question in API response has `id` field |

```

  <assets>

    - GET /api/questions — public question list (exam questions are public, no auth needed in v1)

  </entry_points>
  <threats>

    - T2 (MEDIUM): CORS misconfiguration allowing untrusted origins

  <mitigations>

    - M2 (T2): CORS middleware configured with allow_origins=["http://localhost:5173"] only
    - M3 (T3): Startup event validates JSON file exists and parses, logs error and exits on failure
    - M4 (T4): Default bind to 127.0.0.1 in dev; configurable via env var for production
  </mitigations>
  <verification>

    2. curl http://localhost:8000/api/health returns 200 {"status": "ok"}
    3. curl http://localhost:8000/api/questions returns 200 with 16 questions
    4. Each question in response has id, title, fullText, type, year, source, scorePoints
  </verification>
</threat_model>
```

### Task 02.3: Create question service

<task id="02.3" status="pending">
  <title>Create question service</title>
  <description>
    Implement the service layer that loads questions from the JSON file on startup and provides access methods. The service reads backend/data/questions.json, validates it against the Question model, and exposes a get_all() method.
  </description>
  <read_first>
    - backend/data/questions.json: the data to be loaded
    - backend/app/models/question.py: the Question model (import it)
    - .planning/phases/01-foundation-question-bank/01-CONTEXT.md: D-11 (backend scaffold, data serving)
  </read_first>
  <action>
    Create backend/app/services/question_service.py with:

    ```python
    import json
    from pathlib import Path
    from typing import List
    from app.models.question import Question


    # Hardcoded path relative to service file location
    _DATA_DIR = Path(__file__).resolve().parent.parent.parent / "data"
    _QUESTIONS_FILE = _DATA_DIR / "questions.json"

    _questions: List[Question] = []


    def load_questions() -> List[Question]:
        """Load questions from JSON file into memory.
        
        Returns the loaded Question list. Called once at startup.
        Raises FileNotFoundError if the file doesn't exist.
        Raises json.JSONDecodeError if the file is malformed.
        Raises ValidationError if data doesn't match the Question model.
        """
        global _questions
        
        if not _QUESTIONS_FILE.exists():
            raise FileNotFoundError(f"Questions file not found: {_QUESTIONS_FILE}")
        
        with open(_QUESTIONS_FILE, "r", encoding="utf-8") as f:
            raw_data = json.load(f)
        
        _questions = [Question(**item) for item in raw_data]
        return _questions


    def get_all() -> List[Question]:
        """Return all loaded questions.
        
        Returns empty list if load_questions() hasn't been called yet.
        """
        return _questions


    def get_by_id(question_id: str) -> Question | None:
        """Find a question by its ID.
        
        Returns None if not found.
        """
        for q in _questions:
            if q.id == question_id:
                return q
        return None


    def count() -> int:
        """Return the number of loaded questions."""
        return len(_questions)
    ```

    4. No external dependencies beyond json, pathlib, typing.
  </action>
  <acceptance_criteria>
    1. File backend/app/services/question_service.py exists
    2. Module has functions: load_questions(), get_all(), get_by_id(), count()
    3. `cd backend && python3 -c "from app.services.question_service import load_questions, get_all; qs = load_questions(); print(len(qs))"` prints 16

    ```python
    async def health_check():
        return {"status": "ok", "service": "interview-simulator"}
    ```

    2. Create backend/app/routers/questions.py:
    ```python
    from fastapi import APIRouter, HTTPException
    from typing import List
    from app.services.question_service import get_all, get_by_id
    from app.models.question import Question
    
    router = APIRouter(tags=["questions"])
    
    
    @router.get("/api/questions", response_model=List[Question])
    async def list_questions():
        """Return all scored questions."""
        return get_all()
    
    
    @router.get("/api/questions/{question_id}", response_model=Question)
    async def get_question(question_id: str):
        """Return a specific question by ID."""
        question = get_by_id(question_id)
        if question is None:
            raise HTTPException(status_code=404, detail="Question not found")
        return question
    ```

### Task 02.5: Create FastAPI application with CORS

<task id="02.5" status="pending">
  <title>Create FastAPI application with CORS</title>
  <description>
    Create the main FastAPI application that includes both routers, configures CORS for the frontend dev server, and loads questions on startup. This is the entry point for the server.
  </description>
  <read_first>
    - backend/app/routers/health.py: health check router to include
    - backend/app/routers/questions.py: questions router to include
    - backend/app/services/question_service.py: load_questions to call on startup
  </read_first>
  <action>
    Create backend/app/main.py:
    ```python
    import logging
    from contextlib import asynccontextmanager
    
    from fastapi import FastAPI
    from fastapi.middleware.cors import CORSMiddleware
    
    from app.routers import health, questions
    from app.services.question_service import load_questions
    
    logger = logging.getLogger("interview-simulator")
    
    
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        """Load question data on startup."""
        try:
            count = len(load_questions())
            logger.info(f"Loaded {count} questions from data file")
        except Exception as e:
            logger.error(f"Failed to load questions: {e}")
            raise
        yield
    
    
    app = FastAPI(
        title="Interview Simulator API",
        description="Civil Service Exam Interview Simulator Backend",
        version="0.1.0",
        lifespan=lifespan,
    )
    
    # CORS — only allow frontend dev server
    app.add_middleware(
        CORSMiddleware,
        allow_origins=[
            "http://localhost:5173",
            "http://127.0.0.1:5173",
        ],
        allow_credentials=False,
        allow_methods=["GET"],
        allow_headers=["*"],
    )
    
    # Register routers
    app.include_router(health.router)
    app.include_router(questions.router)
    ```

    Configure logging in a basic way (optional, can just use print for v1). The key point is the lifespan handler calls load_questions() on startup and CORS is restricted to localhost:5173.
  </action>
  <acceptance_criteria>
    1. backend/app/main.py exists with FastAPI app instance
    2. app includes both health.router and questions.router
    3. CORS middleware configured with allow_origins containing localhost:5173
    4. lifespan function calls load_questions() on startup
