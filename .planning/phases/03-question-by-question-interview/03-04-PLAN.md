    Props:
    ```typescript
    interface ProgressIndicatorProps {
      current: number;   // 0-based current question index
      total: number;     // total number of questions (3 or 4)
    }
    ```

    Implementation:
    - Ant Design `Steps` component, `type="default"`, `size="small"`, `direction="horizontal"`
    - Generate `total` steps. `current` determines `status="finish"`, `"process"`, or `"wait"` for each
    - `currentIndex` step gets `status="process"`, completed steps get `status="finish"`, remaining get `status="wait"`
    - Below Steps: `Typography.Text` at 14px, color `#8C8C8C`, content `第 {current+1}/{total} 题`
    - Centered container (flex column, align center)
    - If `total === 0`: render nothing (return null)

    **StatusTextBar.tsx:**

    Props:
    ```typescript
    interface StatusTextBarProps {
      questionStatus: QuestionStatus;  // from types/interview
      currentIndex: number;            // 0-based
      timerRemaining: number;          // seconds remaining for timer display
      ttsError?: boolean;              // true when TTS synthesis failed for current question (UI-SPEC TTS Error state)
    }
    ```

    Implementation:
    - Maps `questionStatus` to status text string:
      - 'idle': "" (empty — page not started)
      - 'reading': if `ttsError === true` then `题目朗读失败，可查看下方题目文字` (per UI-SPEC copywriting contract TTS error state), else `正在朗读第 {currentIndex + 1} 题...`
      - 'thinking': `思考时间剩余 {formatTime(timerRemaining)}`
      - 'answering': `答题时间剩余 {formatTime(timerRemaining)}`
      - 'transition': "" (empty — transition page handles this)
      - 'complete': "" (empty — complete state handles this)
    - Helper function `formatTime(seconds: number): string` that converts seconds to `M:SS` format (e.g., 125 → "2:05")
    - Renders a `<div>` with Text at 14px, color `#262626`, centered
    - Only renders when status text is non-empty
    - Import `QuestionStatus` from `../../types/interview`
    - Note: The `ttsError` state is set by the orchestrator (Plan 05) when `synthesizeSpeech()` throws. The TTS error text comes from the UI-SPEC copywriting contract: "题目朗读失败，可查看下方题目文字". This is a degraded mode — thinking timer still auto-starts so the user isn't stuck.
