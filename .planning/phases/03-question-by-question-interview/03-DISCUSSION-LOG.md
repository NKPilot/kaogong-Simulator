## 计时器（Timer Durations & Behavior）

| 选项 | 描述 | 选中 |
|------|------|------|
| 固定 2min思考/3min答题 | 不可调整，反映真实江苏省考节奏 | ✓ |
| 固定 1min思考/2min答题 | 更短周期，适合快速练习 | |
| 用户可选预设 | 面试前从短/标准/长中选择 | |
| 完全可配置 | 通过设置面板自定义时长 | |

**选择：** 固定 2min 思考 / 3min 答题

---

| 选项 | 描述 | 选中 |

## 流程与状态机（Flow & State Machine）

| 选项 | 描述 | 选中 |
|------|------|------|
| 4 阶段 | 念题→思考→答题→完成 | ✓ |
| 3 阶段 | 思考（含念题）→答题→完成 | |
| 手动控制 | 每阶段用户手动触发 | |

**选择：** 4 阶段（念题→思考→答题→完成）

---

| 选项 | 描述 | 选中 |
|------|------|------|
| 自动推进+过渡页 | 答完展示过渡页，2-3s 后自动跳到下一题 | ✓ |
| 立即自动跳转 | 计时归零立即跳到下一题念题 | |
| 手动点击推进 | 停在该题完成页，用户点「下一题」 | |

**选择：** 自动推进+过渡页

---

| 选项 | 描述 | 选中 |
|------|------|------|
| 仅思考阶段重读，重置计时 | 限 1 次，从头开始 2min 倒计时 | ✓ |
| 全阶段可重读，不重置计时 | 思考或答题中均可重读，计时继续 | |
| 不限次数，重置计时 | 可反复重听但每次都会重置 | |

**选择：** 仅思考阶段可重读，重置计时，限 1 次

---

| 选项 | 描述 | 选中 |
|------|------|------|
| 不恢复，刷新即重置 | v1 简单处理 | ✓ |
| localStorage 恢复 | 刷新后恢复到当前题目和阶段 | |
| 后端会话恢复 | 通过 sessionId 恢复 | |

**选择：** 不恢复，刷新即重置
