    - `startInterview()`: `set({ sessionId: crypto.randomUUID(), currentIndex: 0, questionStatus: 'reading', rereadUsed: false })`

    - `nextQuestion()`: Increment `currentIndex` by 1, reset `questionStatus` to 'reading', reset `rereadUsed` to false, reset `recordingBlob` to null, `recordingDuration` to 0. Does NOT change `sessionId` or `micPermission`.

    - `startTimer()`: Call `set({ timerRunning: true })`. NOTE: actual interval iteration (ticking) is managed by the orchestrator component via setInterval — the store only holds state. The orchestrator calls `resetTimer()` and `pauseTimer()` (equivalent to stop).

    - `pauseTimer()`: `set({ timerRunning: false })`

    - `resetTimer(seconds)`: `set({ timerTotal: seconds, timerRemaining: seconds, timerRunning: true })`

    - `startRecording()`: `async` action. Resolves promise immediately (actual MediaRecorder.start() is in the orchestrator). Sets `recordingBlob` to null (clears previous), `recordingDuration` to 0.

    - `stopRecording()`: `async` action. Stops the recording timer. (Blob and final duration are set by the orchestrator via `useInterviewStore.setState()` since Zustand supports direct state patching without explicit setters — matching the pattern used in Plan 05's timer interval.)

    - `setMicPermission(status)`: Sets micPermission. Used by orchestrator when getUserMedia resolves/rejects.

    - `setRereadUsed()`: `set({ rereadUsed: true })`

    - `setQuestionStatus(status)`: Sets questionStatus. Called by orchestrator on phase transitions.

    - `completeInterview()`: `set({ questionStatus: 'complete' })`. Called after last question's transition phase ends.

    Store export: `export const useInterviewStore = create<InterviewStore>(...)`
