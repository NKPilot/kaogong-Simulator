    **Props interface:**
    ```typescript
    interface TimerRingProps {
      remaining: number;    // seconds remaining in current phase
      total: number;        // total seconds for current phase
      phaseLabel: string;   // "思考时间" or "答题时间"
      running: boolean;     // whether timer is actively counting
    }
    ```

    **Implementation:**

    - Size: 120px outer diameter (SVG viewBox "0 0 120 120")
    - Two `<circle>` elements in SVG:
      - Background track: radius=54 (cx=60, cy=60), stroke=6px, color `#F0F0F0`, fill="none"
      - Progress arc: same geometry, with `strokeDasharray` and `strokeDashoffset` calculated from `remaining / total` ratio
    - Arc starts from top (12 o'clock position): apply transform `rotate(-90 60 60)` to the progress circle so 0% starts at top
    - Stroke color logic (computed from `remaining`):
      - `remaining > 30`: `#BE1E2D` (normal)
      - `remaining <= 30 && remaining > 10`: `#FA8C16` (orange warning)
      - `remaining <= 10`: `#FF4D4F` (red critical)
    - MM:SS text centered inside the circle using absolute positioning over the SVG (div with flexbox, or SVG `<text>` element). UI-SPEC says 40px, weight 700, color follows the same threshold as ring stroke.
    - Phase label above the ring: "思考时间" or "答题时间" in 14px, weight 400, color `#8C8C8C`
    - Pulse animation: apply CSS class `pulse-slow` when `remaining <= 30 && remaining > 10`, `pulse-fast` when `remaining <= 10`. Define CSS `@keyframes` inline in the component file (or in a separate CSS file imported).
      ```
      @keyframes pulse-slow { 0%, 100% { opacity: 1; } 50% { opacity: 0.6; } }
      @keyframes pulse-fast { 0%, 100% { opacity: 1; } 50% { opacity: 0.4; } }
      ```
    - Use `prefers-reduced-motion` media query to disable pulse animations (show static color changes only)
    - Handle edge cases:
      - `total === 0`: show full ring in `#F0F0F0`, display "0:00" in center (loading/initial state)
      - `remaining <= 0`: show full ring arc in `#FF4D4F`, text "0:00" in `#FF4D4F`
      - `remaining > total`: clamp to total, show normal

    **CSS-in-JS pattern**: Use inline `React.CSSProperties` object (per project convention from Phase 1/2). Define styles in a `styles` Record variable at the top of the component.

    **Props interface:**
    ```typescript
    interface RecordingIndicatorProps {
      recordingDuration: number;  // elapsed recording time in seconds
      isRecording: boolean;       // whether recording is active
      micDenied: boolean;         // whether mic permission was denied
    }
    ```

    **Implementation:**

    - When `!isRecording && !micDenied`: render nothing (return null)
    - When `micDenied`: render null here — this component only handles active recording (MicPermissionError is separate per C-07)

    Active recording display:
    - Flex row, centered:
      - Red blinking dot: 10px circle, `#FF4D4F`, with CSS animation `@keyframes blink-recording { 0%,100% { opacity: 1; } 50% { opacity: 0.3; } }` cycle 1.2s
      - Duration text: `录音中 MM:SS` format (MM:SS computed from `recordingDuration`), 14px, color `#262626`
    - Below the row: waveform visualization (CSS-only)
      - 7 horizontal bars, each 4px wide, max height 24px, min height 4px, rounded top (border-radius 2px)
      - Active bars: background `#BE1E2D` with CSS animation `@keyframes wave { from { transform: scaleY(0.5); } to { transform: scaleY(1.2); } }` at 0.8s ease-in-out infinite alternate
      - Each bar has a different `animation-delay` (0s, 0.1s, 0.2s, 0.3s, 0.4s, 0.5s, 0.6s) and a different base height (varies 8-20px range)
      - Container: `display: flex`, `gap: 4px`, `alignItems: center`, `justifyContent: center`
    - When `isRecording` is false (recording just stopped but blob exists): show static bars (idle state, background `#E8E8E8`) with no animation — but this component returns null when not recording per above, so only show during recording.
    - Bar regions: `aria-hidden="true"` (decorative per UI-SPEC)
