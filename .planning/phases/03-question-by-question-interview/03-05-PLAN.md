    **Core effect — question change / phase initialization:**

    A `useEffect` watching `store.currentIndex` and `store.questionStatus` drives transitions:

    - When `questionStatus === 'reading'` and currentIndex changed or page mounted:
      1. Reset `ttsError` to false (new question starts clean)
      2. Generate sessionId if first question (store.startInterview)
      3. Fetch TTS for currentQuestion.fullText via `synthesizeSpeech()` — **wrapped in try/catch**:
         - **On success**: Set audio element src from blob URL, attempt auto-play (try/catch NotAllowedError -> set playBlocked)
         - **On failure**: Call `setTtsError(true)`, then auto-advance to thinking phase (set store questionStatus to 'thinking', reset timer to THINKING_TIME). This implements the UI-SPEC TTS Error degraded mode: user sees "题目朗读失败，可查看下方题目文字" in StatusTextBar and the thinking timer starts so they are not stuck.
      4. Set store status to reading
      5. Auto-play block overlay (same pattern as ExamRoomPage: full-screen overlay with play button)

    - When TTS audio `ended` event fires (`handleTtsEnded`):
      1. Set store questionStatus to 'thinking'
      2. Reset timer to `THINKING_TIME` (120s)
      3. Start timer interval (setInterval 1s decrement)
      4. Re-read button becomes available

    - When thinking timer reaches 0 (handled by **timer-zero useEffect** — see below):
      1. Pause timer
      2. Set store questionStatus to 'answering'
      3. Reset timer to `ANSWERING_TIME` (180s)
      4. Start timer interval (setInterval 1s decrement)
      5. Request microphone via `navigator.mediaDevices.getUserMedia({ audio: true })`
      6. On success: create MediaRecorder, start recording
      7. On NotAllowedError: set micPermission to 'denied', show MicPermissionError

    - When answering timer reaches 0 (handled by **timer-zero useEffect** — see below):
      1. Pause timer
      2. Stop MediaRecorder
      3. Collect recording blob from chunks
      4. Set recordingBlob in store via `useInterviewStore.setState({ recordingBlob: blob })`
      5. Set questionStatus to 'transition'
      6. Fire-and-forget upload via `uploadRecording(store.sessionId, store.currentIndex, blob)` (D-10: silent, not awaited)
      7. Start transition timeout (2.5s)

    - When transition timeout fires:
      1. Close the question drawer for next question: `setDrawerVisible(false)` (D-13: drawer starts closed per question)
      2. If more questions remain: call store.nextQuestion(), start TTS for next question
      3. If last question: call store.completeInterview(), navigate to `/results` (Phase 4 route)

    **Timer-zero useEffect (INFO 5: explicit dependency array):**

    A dedicated `useEffect` watching `store.timerRemaining` and `store.timerRunning` detects when the countdown reaches zero:

    ```typescript
    useEffect(() => {
      if (store.timerRemaining === 0 && store.timerRunning === false && store.questionStatus === 'thinking') {
        handleThinkingEnded();
      } else if (store.timerRemaining === 0 && store.timerRunning === false && store.questionStatus === 'answering') {
        handleAnsweringEnded();
    ```

    The timer interval decrements `timerRemaining` via `useInterviewStore.setState()`. When it hits 0, the interval calls `pauseTimer()` which sets `timerRunning` to false, triggering this effect. The `store.questionStatus` guard prevents double-firing.

    **Re-read handler (`handleReRead`):**

    5. Call store.resetTimer(THINKING_TIME) — resets timer to 120s (D-17)

    **MediaRecorder setup:**

    ```typescript
    const handleStartRecording = async () => {
      try {
        const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
        mediaStreamRef.current = stream;
        store.setMicPermission('granted');

        const recorder = new MediaRecorder(stream, {
          mimeType: 'audio/webm;codecs=opus'
        });
        mediaRecorderRef.current = recorder;
        recordingChunksRef.current = [];

        recorder.ondataavailable = (e) => {
          if (e.data.size > 0) recordingChunksRef.current.push(e.data);
        };

        recorder.onstop = () => {
          const blob = new Blob(recordingChunksRef.current, { type: 'audio/webm' });
          // Store blob and start background upload -- use setState directly since InterviewStore
          // has no dedicated setRecordingBlob setter (per Zustand convention; see Plan 02 Task 1 note).
          useInterviewStore.setState({ recordingBlob: blob });
          uploadRecording(store.sessionId, store.currentIndex, blob).catch(console.error);
          // Cleanup tracks
          mediaStreamRef.current?.getTracks().forEach(t => t.stop());
        };

        recorder.start(1000); // emit dataavailable every 1s
        recordingStartTimeRef.current = Date.now();
        // Start recording duration interval -- use setState directly (same reasoning as above)
        recordingIntervalRef.current = window.setInterval(() => {
          const elapsed = Math.floor((Date.now() - recordingStartTimeRef.current) / 1000);
          useInterviewStore.setState({ recordingDuration: elapsed });
        }, 1000);
      } catch (err) {
        if (err instanceof DOMException && err.name === 'NotAllowedError') {
          store.setMicPermission('denied');
        }
      }
    };
    ```

    **Timer interval management:**

    ```typescript
    const startTimerInterval = () => {
      // Clear existing interval
      if (timerIntervalRef.current) clearInterval(timerIntervalRef.current);
      timerIntervalRef.current = window.setInterval(() => {
        const state = useInterviewStore.getState();
        if (state.timerRemaining <= 0) {
          clearInterval(timerIntervalRef.current!);
          timerIntervalRef.current = null;
          useInterviewStore.setState({ timerRunning: false });
          // Timer reached zero — handled by the timer-zero useEffect above
          return;
        }
        useInterviewStore.setState({ timerRemaining: state.timerRemaining - 1 });
      }, 1000);
    };
    ```
