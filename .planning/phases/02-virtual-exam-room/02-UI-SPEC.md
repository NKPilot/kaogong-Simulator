### Guidance Text Content (returned by GET /api/interview/guidance)

The API returns structured JSON with the following copy pattern:

```json
{
  "title": "面试说明",
  "paragraphs": [
    "考生你好，欢迎参加本次公务员模拟面试。",
    "本次面试共 N 道题，采用结构化面试形式。请仔细听题，在思考后作答。",
    "每道题有思考时间和答题时间限制，请合理分配时间。",
    "准备好了吗？点击「开始答题」进入第一题。"
  ]
}
```

- `N` is dynamically populated from the user's selected question count.

```
+--------------------------------------------------+
| AppLayout Header (sticky)                          |
| "江苏公务员面试模拟器" (20px white on #BE1E2D)      |
+--------------------------------------------------+
|                                                    |

|                                                    |
|   Examiner Row (centered, ~960px max-width)         |
|   [考官] [考官] [主考官] [考官] [考官]               |
|   5 images, each ~160x200px, rounded corners        |
|   Name labels beneath each image                    |
|                                                    |
|   Guidance Panel (expandable)                       |
|   [查看/收起引导语文字] toggle button               |
|   Paragraph text, 16px, max-width ~720px            |
|                                                    |
|   TTS Controls                                      |
|   [播放/暂停] [重播] + "正在播放引导语..." status     |
|                                                    |
|   CTA Button                                        |
|   [开始答题] primary button, centered               |
|                                                    |
+--------------------------------------------------+
```

**Key layout rules:**
- The exam room page MUST override the AppLayout Content padding (32px) to achieve full-width red banner. Either set Content padding to 0 on this route, or have the page render outside the Content wrapper. RECOMMENDED: Keep AppLayout but set `style={{ padding: 0, maxWidth: '100%' }}` on Content.
- Examiner row and controls area use `max-width: 960px` centered within the full-width page.
- Red banner spans the entire viewport width with no lateral padding.
- Desktop-first: minimum viewport width 1024px recommended. Below 900px, examiner images scale down proportionally.

## Components

| Property | Specification |

### C-02: ExaminerRow

| Property | Specification |
|----------|---------------|
| Role | Horizontal row of 5 examiner images |
| Layout | flex, centered, gap 16px, max-width 960px, margin-top 24px |
| Image size | ~160px wide x ~200px tall, object-fit: cover, border-radius: 8px |

| Label text | Center image: "主考官", all others: "考官" |

### C-03: GuidanceToggle

| Property | Specification |
|----------|---------------|
| Role | Expandable/collapsible text panel showing guidance content |

| Container | White background, border-radius 6px, padding 16px, max-width 720px centered |

### C-04: TTSControls

| Property | Specification |

| Error state | If TTS API fails, show "语音播放失败，请查看下方文字" and hide controls |
| Loading | Show `Spin` component during TTS audio fetch |

### C-05: CTAButton

| Property | Specification |
|----------|---------------|
| Label | "开始答题" |
| Type | `primary` (Ant Design) |
| Size | `large` |

| Property | Specification |

## States

### Page-level States

| State | Condition | Visual |
|-------|-----------|--------|
| Loading | TTS audio is being fetched | `Spin` in TTS controls area, banner + examiners visible immediately |
| Ready | TTS loaded, auto-playing or paused | All components visible, TTS status shows playback state |
| TTS error | Backend TTS API fails | Error text shown, controls hidden, guidance text still expandable |
| Empty | Edge case: no examiners directory or zero images | Show 5 silhouette placeholders with name labels |

### GuidanceToggle States

| State | Visual |
|-------|--------|
| Collapsed (default) | Button says "查看引导语文字" with `DownOutlined` icon, text panel hidden |
| Expanded | Button says "收起引导语文字" with `UpOutlined` icon, text panel visible with smooth open animation |

### TTSControls States

| State | Visual |
|-------|--------|
| Loading | `Spin` component, no buttons visible |
| Playing | Play/Pause button shows Pause icon, status "正在播放引导语..." |
| Paused | Play/Pause button shows Play icon, status "已暂停" |
| Ended | Play/Pause button shows Play icon (replay available), status "播放完毕" |
| Error | Error text only, no buttons, no Spin |

## Interactions

| # | Trigger | Behavior |
|---|---------|----------|
| I-01 | Page mounts | Entry animation plays (fade-in 600ms). TTS audio fetch starts immediately. |
| I-02 | TTS audio loaded | Auto-play begins with user interaction (browser autoplay policy requires user gesture first). If blocked, show "点击播放" overlay. |
| I-03 | User clicks Play/Pause | Toggles audio playback. Button icon switches accordingly. |
| I-04 | User clicks Replay | Seeks audio to 0 and starts playback. |
| I-05 | User clicks guidance toggle | Expand/collapse guidance text panel with smooth height transition. |
| I-06 | User clicks "开始答题" | Navigate to Phase 3 route (first question view). TTS audio stops if still playing. |
| I-07 | TTS finishes naturally | Controls update to "播放完毕" state. No auto-repeat. |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Guidance text | Readable at 16px with 1.6 line-height, sufficient color contrast on white (#262626 on #FFFFFF = 16:1) |
| Banner text | 28px white on #BE1E2D is a 5.5:1 contrast ratio — meets AA for large text |
| TTS fallback | When TTS fails, text is always available via toggle — no information is lost |
| Button labels | All buttons use semantic text labels (not icon-only) |
| Keyboard navigation | All interactive elements (toggle, buttons) focusable and activated with Enter/Space |
| Focus indicators | Ant Design default focus rings on all controls |

## API Contracts

### GET /api/interview/guidance?question_count=N

**Response:**
```json
{
  "title": "面试说明",
  "paragraphs": ["...", "...", "..."]
}
```

### POST /api/tts/synthesize

**Request:**
```json
{
  "text": "考生你好，欢迎参加本次公务员模拟面试。",
  "voice": "male-formal"
}
```

**Response:** Streamed audio bytes (chunked transfer encoding, content-type `audio/mpeg`).
